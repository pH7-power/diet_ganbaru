# 💪 ダイエット トラッカー (Diet Tracker)

スマートフォン最適化された、シンプルで美しい入力画面で毎日の体重・運動・食事を記録するプレミアムWebアプリケーションです。

🎯 **目標**：2026年10月31日までに 78.0kg → 70.0kg に減量  
🔥 **戦略**：過度な食事制限ではなく、運動量の増加（消費カロリーUP）で健康的に減量

---

## 📱 アプリの利用方法

### ① Web版としてスマホから使う（おすすめ / GitHub Pages）
GitHub Pagesを有効化すると、スマホのブラウザ（Safari / Chrome）からいつでもアクセスできます。

🔗 **WebアプリURL**:  
👉 **[https://ph7-power.github.io/diet_ganbaru/](https://ph7-power.github.io/diet_ganbaru/)**

> **💡 GitHub Pagesの有効化手順（初回のみ・30秒）:**
> 1. このリポジトリ右上の **「Settings」**（歯車マーク）を開く
> 2. 左メニューの **「Pages」** をクリック
> 3. **Branch** を `None` → `main` (または `master`) に変更し **「Save」** を押す
> 4. 数分後、上記URLにアクセスするとスマホからアプリがそのまま動きます！

---

### ② パソコン・ローカルで使う
フォルダ内の **`index.html`** または **`ダイエット記録アプリ.html`** をダブルクリックするだけで、サーバー不要・完全スタンドアロンで即起動します。

---

## ✨ 主な機能

- 📊 **ホーム（ダッシュボード）**
  - 現在の体重・目標達成度（%）・減量達成数・週間運動時間をひと目で確認
  - 体重推移グラフ & 運動別消費カロリー推移グラフ（リアルタイム更新）
  - 週間サマリー（推定消費・摂取カロリーおよび収支バランス）
- ➕ **記録（かんたん入力）**
  - **体重記録**: 朝の計測値を大きく直感的に入力
  - **運動記録**: 運動種別を選ぶだけで推定消費カロリーを自動計算（ランニング、ジム、水泳、球技など）
  - **食事記録**: ざっくりとした食事内容と推定カロリーを入力
- 🎯 **進捗 & 目標ペース**
  - ゴールまでの残り日数・残り減量数
  - 1日に必要な目標カロリー赤字（運動＋食事制限の目安ペース）を自動算出
  - 過去の記録履歴一覧
- ⌚ **Garmin・Appleヘルスケア連携**
  - Garminアクティビティ（TCX/GPX）やヘルスケアCSVのドロップ取り込み
  - iPhoneショートカット経由でのワンタップ自動体重・運動記録
- 💾 **データ自動保存 & エクスポート**
  - ブラウザのローカルストレージへ即時自動保存
  - 右上の「出力」ボタンからいつでもJSONバックアップをダウンロード可能

---

## ⌚ Garmin / スマートウォッチ連携について

Garminスマートウォッチをご利用の場合、Garmin Connectアプリの設定で**「Apple ヘルスケア（または Google Health Connect）」との連携をON**にしておくと、Garminが測定した正確な消費カロリーや体重が自動でスマホに届きます。

アプリ右上の **「⌚ 連携」** ボタンから、データのインポートや連携テストをお試しいただけます。
